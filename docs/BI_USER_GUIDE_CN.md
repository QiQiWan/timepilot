# TimePilot BI 使用手册（v0.24.6）

进入「项目 → 数据资产 → 进入 BI」，即可在全屏工作区使用 Perspective 查看数据和制作分析图表。顶部的「使用手册」会在当前页面打开分类说明，不会跳走或清空图表。

## 1. 浏览数据

从项目资产清单打开数据表，可以在 Perspective 的 **Datagrid** 中查看字段、行和类型。需要确认字段原名时，在右下角打开分析助手并输入「查看数据字段」。也可以输入「查看前20行」获取受限预览。

## 2. 图表与数据系列

打开 Perspective 的配置面板，选取需要的图表类型，将字段拖入数值区域或 X 轴、Y 轴。图表支持多个数值系列。切换图表插件时，系统会尝试保留当前面板之前的系列选择、排序和筛选，并跳过新图表不兼容的字段。原生 Perspective 在仅设置 `plugin` 时会恢复插件默认列，因此需要上述补偿机制。操作失败时保留安全的默认配置，结果仍可手动修改。

透视分析中，使用 Group By 按行分组、Split By 按列拆分，然后为字段选择平均、求和、最大值、计数等可用聚合。多面板布局可以保存和恢复。筛选、透视及图表切换只修改视图，不会自动修改数据原件。

## 3. 分析助手

右下角圆形按钮打开分析助手。拖动深色标题栏移动窗口；桌面端拖动右下角可以调整窗口宽高。右上角 **×** 关闭，仍可通过圆形按钮重新打开。窗口尺寸按用户、项目及资产保存。

常用操作包括：查看数据字段、查看前20行、求两列之和、移动平均、按字段排序等。推荐操作按钮会先填入输入框，用户可修改后执行。

计算字段、时间聚合、移动平均与关联表可通过应用内表单选择真实字段，无需在浏览器原生提示框输入字段名。字段选择框支持「使用当前图表系列」，它从当前 Perspective 工作区读取已选中的字段；没有兼容字段时，直接在列表中选择。

## 4. 数据计算与时间语义

计算字段产生只读结果预览，支持合法字段间的加、减、乘、除；除零按服务端计算语义处理。移动平均需要数值字段、顺序依据和窗口点数（2—240）；没有确认的日期时间字段时，可按源记录顺序计算，不得据此声称数据按月/小时排列。

「按时间汇总」要求真实日期时间列，可以选平均值、合计、最小值、最大值或计数等聚合。A1/A2 等无业务含义字段不会被系统自动推断成温度或销量。

## 5. 保存图表与正式发布数据

顶部「保存视图」保存当前字段、图表类型、面板布局、筛选条件与固定资产版本。高级操作里的「编辑数据」会先显示预览，再生成新的版本。撤销或版本恢复不会直接删除原件。

将计算列、关联表或时间聚合结果用于正式建模前，请从「其他操作 → 发布数据和建立模型」申请生成完整的新资产，经过来源、范围和权限检查。BI 中的前 N 行预览不能代替完整模型训练数据。

## 6. 性能与恢复

真实全量模式由后台数据引擎支持 Perspective 远程数据接口；如果只有采样预览，应以页面的行数/范围标识为准，不能当作全量统计。在断网或页面刷新后，重新打开当前资产，并通过保存视图恢复图表。当前版本需要在目标机完成实际 DuckDB / Arrow / Perspective 5.6.1 JS/WASM 验收。

## 7. 常见问题

- **切换图表后某个系列不见了**：新插件可能不接受该字段类型（例如散点图要求至少两个可用数值字段），在原生设置中检查数值系列。
- **为什么无法按时间汇总**：确认数据时间字段类型；数字序号 `Time` 没有确认时间单位时不能当作时间戳。
- **为什么计算结果不能直接训练**：先审批生成完整数据资产，保证源哈希、记录范围与特征产生时刻可追溯。
- **为什么某个工具不可用**：服务端权限、数据类型及实际 Perspective 插件能力必须全部满足。

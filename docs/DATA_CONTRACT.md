# TimePilot 数据契约 V1.0

## 目标和运行语义

**外部格式灵活，内部数据契约稳定。** 当前可读取 CSV、XLSX、Parquet，转换为单一长表结构。在 v0.1 中，训练目标限于一条序列的单一连续数值目标；多变量设备状态、已知未来外生特征与层级需求约束作为后续扩展。

核心字段：

| 字段 | 语义 | 当前约束 |
|---|---|---|
| `series_id` | 设备、车型、客户项目等连续序列标识 | 不可空，可重复出现在不同时间 |
| `timestamp` | 统计周期标记。`MS` 表示月初 | 可解析到 UTC，单序列时间不重复 |
| `target` | 需要预测的连续数值 | 非空、有限数；负值保留但发出警告 |
| `available_at` | 数据实际可用于建模的时间 | 非空；超过预测原点的数据不可使用 |

**注意：** `available_at` 不等于 `ingested_at`，统计月份标签也不代表真实的发布日。若业务方无法提供历史可用时间，允许明确声明 `publication_lag_days` 生成有警告的研究版本；正式效果报告应使用真实数据发布与修订记录。

所有时间转为 UTC ISO8601 字符串，单序列按照时间排序。对不符合 `MS` / `D` / `h` 频率、跨期跳点、重复 `(series_id,timestamp)` 的输入，在正式训练前拒绝。设备原生毫秒级数据、工艺事件及任意采样频率将通过后续的设备数据适配器接入。

## 数据集导入流程

1. 用户上传原始文件，服务限制文件大小，保留来源哈希。
2. `normalize_frame` 验证列、类型、重复、时区、缺失、异常值。
3. 生成标准化 CSV 和 `DatasetManifest`，分别保留原始 SHA256 和标准快照 SHA256；数据库保存可查找元数据。
4. 任何一次建模操作均校验快照文件 SHA256。修改数据必须创建新数据集版本，不能覆盖。
5. 将数据快照与 `TaskSpec`、插件版本、Python 版本、评价协议关联到 `run_manifest.json`。

## 冻结评测

设最后 `h` 个观测周期为**独立测试**，在其之前使用 `k` 个滚动预测原点进行模型验证。同一个实体上，模型只通过前面的 `k` 个窗口排名；之后固定选择的模型并评测最后 `h` 个点。输出 WAPE、MAE、RMSE、MASE（当季节性缩放可定义时）、Bias。所有候选模型使用相同数据分割。独立测试不能用于重新挑选候选模型。

若历史数据按统计周期多次修订，独立历史回测应使用 **point-in-time snapshot**，目前的单快照格式只保证对 `available_at` 的过滤，并不完整恢复每一个历史发布版本。真实产品需求预测前需增加双时间版本化原始库。

## 质量等级

- 阻断：无目标字段、无时间字段、重复键、严重时间泄漏、目标非法、不可用模型、数据快照被篡改。
- 警告：含负目标、可用时间为人为推定、独立测试样本偏少、WAPE 分母为零。
- 复核：候选模型在验证窗口表现良好，但尚未提供业务准入阈值、正式审批或足够统计证据。

系统不会自动删除负订单、删除异常工况或擅自更改时间和单位。

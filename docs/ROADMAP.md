# TimePilot 后续研发清单

## 首要验收

- 在 macOS Python 3.12.12 上运行真实 Perspective、DuckDB、Parquet、WebSocket 闭环，`reports/native_bi_acceptance.json` 的每个阶段必须通过。
- 使用真实浏览器验证拖拽透视、图表、保存/刷新、编辑后版本切换和实时增量更新，不以模拟页面截图代替功能验收。
- 对每一种失败建立稳定的功能测试，并逐步清理临时诊断程序，避免无限累积修补脚本。

## 性能与数据治理

- 百万、千万行数据集的服务端聚合、浏览器响应和内存占用实测。
- Parquet 稀疏补丁压实、长版本链延迟优化、并发编辑冲突解决。
- 企业身份认证、资产级权限、审计、备份恢复、任务执行资源隔离。

## 科研与算法

- 完整 BI → 预测建模 → TQE 质量报告 → Agent 实验优化工作流。
- 机理可信度识别、混合动力学、跨工况泛化及多模型对比。
- 与企业数据平台对接、模型推理服务和持续数据更新。

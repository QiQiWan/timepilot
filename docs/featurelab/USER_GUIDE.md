# FeatureLab 2.0 使用手册（v0.25.2）

从项目中的**特征工程**进入。先在**数据管理**上传并发布数据表；数据文件与业务字段名不会被 FeatureLab 改写。

## 一、数据画像

在顶部选择一个已发布资产，默认进入「数据画像」。点击「检查字段含义」核实原字段类型、设备键、时间字段、单位及用途。`Time=1…506` 只代表记录序号，不能直接选择为真实采集时间。点击「生成完整画像」，任务可在重新打开页面后继续查询。每张画像都记录来源 SHA、契约版本、扫描行数及统计范围。

- **数据可以没有时间字段**：仍可计算缺失、范围、行序特征，不会假称分钟级趋势。
- **正式预测需要时间信息**：确认事件发生时间、业务数据可用时间、预测决策时间和标签可用时间。来自 CSV 的文本日期需要受控类型转换后才能确认。
- **计算中断**：通过「刷新状态」查看，服务重启后由任务库恢复；失败任务由后端保留错误码，可重试。

## 二、构造特征

打开「构造特征」，选择字段和计算方法，填写输出名称。已实现的首批运算包括两列加减乘除、最近 N 条记录的滞后/差分、滚动均值/标准差/最小值/最大值。参数按字段类型与设备分组受控校验。

先点击「加入待保存特征」，可连续添加多个步骤；再保存特征集草稿并执行全量计算。计算期间不修改源资产；成功后生成带 SHA 的独立 Parquet 结果。执行状态 `queued/running/succeeded/failed_*` 以服务端为准。

**示例：** 使用 A1、A2 分别生成最近 5 条记录的滚动均值，输出 A1_ma5、A2_ma5。没有可靠采样间隔时，不能用“最近 30 分钟”冒充 5 条记录。若希望窗口以分钟为单位，需要等待 duration-window 执行器通过验收。

## 三、实验评价

「实验评价」提供两种模式：

- **无标签探索**：展示质量、特征数量与来源说明；不会宣称模型准确率或增益。
- **有监督评价**：必须有标签列、预测时点、标签业务可用时间及已完成的全量物化结果；先创建固定切分的实验计划，再启动作业。

现有数值基线使用 NumPy 的岭回归/二分类逻辑回归。预处理参数只在训练折拟合；模型与标签折保持一致。训练数据按标签可用时点筛选。结果包含每一折的样本量、训练截止、预测指标和训练折内冗余诊断。**这是一组基础对照算法，尚未完成复杂模型或机制特征的正式基准。**

## 四、特征资产

在「特征资产」浏览草稿、待审核、已审核、已发布状态。先完成全量计算，再提交审核；审批必须由有权限的人员明确确认，企业模式下审批人与创建人分离。发布时再次检查配方、来源版本和结果 Parquet SHA，生成独立不可变资产，可从 BI 打开。旧 `FeatureRecipe` 保留原语义与接口。

## 五、特征助手

右下角「特征助手」支持“查看数据字段”“查看数据画像”“推荐适合当前数据的特征”“A1 和 A2 相加放到新列”“对 A1 和 A2 计算移动平均”等命令。明确请求先由规则转成受限工具；复杂请求可在已有 API 设置中授权模型，系统随后执行工具校验和实际服务调用。无法执行时显示字段、能力或时间语义缺口，绝不输出已完成的空计划。

**边界：**助手不能批准发布、修改跨项目资产、执行自由 SQL 或访问服务器绝对路径。使用人工模型服务会受模型设置的权限与数据传输策略影响。

## 七、v0.25.3—v0.25.6：预览、特征对照及任务恢复

- **安全时间字段**：事件时刻与数据可用时刻必须来自可信日期/时间字段，并明确时区。设备行号、数值代码不能直接确认成时间。正式预测必须在计划、计算及评价阶段复查预测时点与物化证据。
- **特征预览**：在「构造特征」选中已保存特征集，点击「预览」。预览作业使用独立任务 ID、返回行数上限和扫描预算；不会发布或生成正式 Parquet。大表超出预算将要求缩小范围或正式提交全量作业。
- **分钟/小时窗口**：只有确认事件时间和实体分区后，才能选择时长窗口。`Time=1..506` 等序号无法代替时间。晚到数据应在监督预检中触发阻断。
- **对照查看**：在特征构造页打开 Perspective，再选择成功物化的特征结果「对照」；结果以当前授权项目的附加表进入同一数据连接。可手动切换图表、选择系列并保存工作区。保存工作区时会检查用户身份、数据 SHA 和修订号；版本冲突需要先刷新。
- **配方修订**：修改配方后生成不可变历史快照；旧版已覆盖而缺乏原始记录的历史不自动伪造。通过修订差异查看操作变更。
- **Agent 执行**：明确指令可执行草稿创建与预览两个步骤，任务执行未完成会显示等待。失败时可人工提供反馈并发起有限重规划，带副作用的成功步骤不会在重规划时重复执行。运行记录可以刷新恢复。

### 分阶段验收

```bash
bash TIMEPILOT.sh source-check
bash TIMEPILOT.sh accept feature-safety-v0253
bash TIMEPILOT.sh accept feature-preview-v0254
bash TIMEPILOT.sh accept feature-perspective-v0255
bash TIMEPILOT.sh accept feature-agent-v0256
bash TIMEPILOT.sh accept feature-agent-v0256 --mode configured
```

`offline` 的成功只能证明源码/API/模拟组件；`configured` 需 Python 3.12.12、DuckDB、PyArrow、已编译 Perspective JS/WASM 及系统 Chrome。尚未建立真实 FeatureLab 对照图表的独立浏览器 E2E 测试之前，不应标记整个特征对照工作流已完成正式验收。
